# 第 2 关 · 中段定格

- **关卡编号 (levelIndex)**: 2
- **难度**: ★
- **区段数**: 6（固定）
- **时钟中心值 (centerCap)**: ∞（`"inf"`）—— 本关无每区段点数上限
- **牌堆 (deck)**: 全局牌库 24 张（白 1–12 + 黑 1–12），每局随机抽 12 张发牌；本关使用点数范围与牌数约束
- **设计意图**: 引入中段的**点数范围**与相邻区段的**精确牌数**要求，让玩家在维持总和非递减的同时安排区段 3/4 的容量。

## 通关条件

人类可读：

- 区段 3 的**总和**必须在 **8–12 点**（含 8 和 12）之间。
- 区段 4 **必须恰好放 3 张牌**，不限制颜色。
- 同时满足永久通用规则：区段总和非递减、每段至少 1 张；本关每段总和无上限。

结构化（区段编号 1–6）：

```json
[
  { "type": "sum-range", "segment": 3, "min": 8, "max": 12 },
  { "type": "exact-cards", "segment": 4, "count": 3 }
]
```

## 备注

- “第三个格子限制点数在 8-12”按**区段 3 总和落在 [8, 12]**（`sum-range`）理解。
- “第四个格子必须也是正好三张牌”按**恰好 3 张**（`exact-cards`）理解，黑白颜色均可。
- 其他区段没有本关特殊限制，但仍受永久通用规则约束。
- `centerCap: "inf"` 表示不派生 `max-sum-each`，因此本关没有“每个区段总和 ≤ 24”的限制。
- 结构化条件只写本关特殊条件；三条永久通用规则由加载器自动叠加。
