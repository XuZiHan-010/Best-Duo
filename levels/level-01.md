# 第 1 关 · 拾级而上

- **关卡编号 (levelIndex)**: 1
- **难度**: ★★
- **区段数**: 6（固定）
- **时钟中心值 (centerCap)**: ∞（`null`）—— 每区段无上限，本关只考验跨区段非递减关系
- **牌堆 (deck)**: 全局牌库 24 张（白 1–12 + 黑 1–12），每局随机抽 12 张发牌（本关条件与具体数值无关）
- **设计意图**: 入门关，引入**跨区段关系**。玩家在看不到队友手牌、桌面又全暗的情况下，要靠讨论约定与提示标记，让 6 个区段的总和从左到右不下降。

## 通关条件

人类可读：

- 各区段总和**非递减**：区段 1 的总和 ≤ 区段 2 ≤ 区段 3 ≤ 区段 4 ≤ 区段 5 ≤ 区段 6。

结构化（区段编号 1–6）：

```json
[
  { "type": "non-decreasing", "segments": [1, 2, 3, 4, 5, 6] }
]
```

## 备注

- 允许相等（用“非递减 ≤”，不是严格递增）。如需严格递增请改用 `increasing`。
- 是否同时要求“每段至少 1 张”由设计决定：当前**仅要求非递减**；若某区段为空其总和按 0 计，仍可能满足非递减。如需叠加放满约束，追加 `{ "type": "all-nonempty" }`。
