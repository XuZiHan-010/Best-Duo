# 第 1 关 · 精打细算

- **关卡编号 (levelIndex)**: 1
- **难度**: ★
- **区段数**: 6（固定）
- **时钟中心值 (centerCap)**: ∞（`"inf"`）—— 本关无每区段点数上限
- **牌堆 (deck)**: 全局牌库 24 张（白 1–12 + 黑 1–12），每局随机抽 12 张发牌 —— 本关使用颜色与牌数约束
- **设计意图**: 引入最基础的**指定区段颜色与牌数要求**。玩家需要确认区段 1 只放一张白牌，同时让区段 6 恰好承载 3 张牌，其余区段按全局规则完成非递减排列。

## 通关条件

人类可读：

- 区段 1 **必须且只能放 1 张白色牌**。
- 区段 6 **必须恰好放 3 张牌**，不限制颜色。
- 同时满足永久通用规则：区段总和非递减、每段至少 1 张；本关每段总和无上限。

结构化（区段编号 1–6）：

```json
[
  { "type": "segment-colors", "segment": 1, "black": 0, "white": 1 },
  { "type": "exact-cards", "segment": 6, "count": 3 }
]
```

## 备注

- “第一个格子只能有 1 张白色牌”按**恰好 0 张黑牌 + 1 张白牌**（`segment-colors`）理解，因此区段 1 总牌数也被锁定为 1。
- “最后一个区间必须是正好 3 张牌”按**恰好 3 张**（`exact-cards`）理解，黑白颜色均可。
- 这两条牌数条件会在时钟上显示：区段 1 显示 1 张白色提示卡，区段 6 显示 3 张不指定颜色的提示卡。
- `centerCap: "inf"` 表示不派生 `max-sum-each`，因此本关没有“每个区段总和 ≤ 24”的限制。
- 系统**发牌前已做可解性校验**：抽到无解牌面会自动重抽，因此玩家拿到的牌一定存在满足本关条件的方案（见 [rules.md](../rules.md)）。
- 结构化条件只写本关特殊条件；三条永久通用规则由加载器自动叠加。
