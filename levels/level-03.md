# 第 3 关 · 黑白有序

- **关卡编号 (levelIndex)**: 3
- **难度**: ★★★★
- **区段数**: 6（固定）
- **时钟中心值 (centerCap)**: ∞（`null`）—— 本关考验出牌顺序与配色，不另设每区段上限
- **牌堆 (deck)**: 全局牌库 24 张（白 1–12 + 黑 1–12），每局随机抽 12 张发牌；本关用到卡牌的**颜色**维度
- **设计意图**: 引入两类全新约束——**出牌顺序锁定落点**与**区段配色**。前两手必须按约定落子，逼队伍在禁沟通前就敲定“谁先出、放哪里”，再靠盲打把指定颜色凑进区段 4。

## 通关条件

人类可读：

- **第 1 张**打出的牌（抢到先手者打出的那张）必须落在**区段 3**。
- **第 2 张**打出的牌（后手打出的那张）必须落在**区段 2**。
- **区段 4** 必须**恰好一黑一白**（即恰好 2 张：1 张黑牌 + 1 张白牌）。

结构化（区段编号 1–6；`order` 为 1 起的出牌序号）：

```json
[
  { "type": "placement-order", "order": 1, "segment": 3 },
  { "type": "placement-order", "order": 2, "segment": 2 },
  { "type": "segment-colors", "segment": 4, "black": 1, "white": 1 }
]
```

## 备注

- **约束范围只针对前两张牌**：第 3 张及以后落在哪个区段不限（除区段 4 的配色要求外）。
- `placement-order` 在揭示时按各牌的 `placedAt` 排序判定第 N 张的落点；游戏中交替出牌、且每手之间有提示窗口，出牌时间天然不重叠。
- `segment-colors` 取**恰好** 1 黑 1 白：这同时把区段 4 的张数锁成 2。若本意是“**至少**各一、张数不限”，需要另设一个“至少”语义的配色条件类型。
- 卡牌颜色与数值一样在揭示时才对全队公开；盲打阶段桌面暗牌不暴露颜色。
