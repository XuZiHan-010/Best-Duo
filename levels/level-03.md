# 第 3 关 · 先手定位

- **关卡编号 (levelIndex)**: 3
- **难度**: ★
- **区段数**: 6（固定）
- **时钟中心值 (centerCap)**: ∞（`"inf"`）—— 本关无每区段点数上限
- **牌堆 (deck)**: 全局牌库 24 张（白 1–12 + 黑 1–12），每局随机抽 12 张发牌；本关含具体点数与出牌顺序约束
- **设计意图**: 把**先手落点**与**末段点数范围**叠加。前两张牌锁定关键区段，最后一个区段需要承载 20–30 点，同时不再限制单区段总和上限。

## 通关条件

人类可读：

- **最后一个区段（区段 6）**的总和必须在 **20–30 点**（含 20 和 30）之间。
- **第 1 张**打出的牌必须落在**区段 3**。
- **第 2 张**打出的牌必须落在**区段 2**。
- 同时满足永久通用规则：区段总和非递减、每段至少 1 张；本关每段总和无上限。

结构化（区段编号 1–6；`order` 为 1 起的出牌序号）：

```json
[
  { "type": "sum-range", "segment": 6, "min": 20, "max": 30 },
  { "type": "placement-order", "order": 1, "segment": 3 },
  { "type": "placement-order", "order": 2, "segment": 2 }
]
```

## 备注

- “最后一个格子限制点数 20-30”按**区段 6 总和落在 [20, 30]**（`sum-range`）理解。
- “第三个格子必须是第一个出的牌放置的位置”按**第 1 张牌必须落在区段 3**（`placement-order`）理解。
- “第二个格子是第二张牌出的放置的位置”按**第 2 张牌必须落在区段 2**（`placement-order`）理解。
- `centerCap: "inf"` 表示不派生 `max-sum-each`，因此本关没有“每个区段总和 ≤ 24”的限制。
- 系统**发牌前已做可解性校验**：抽到无解牌面会自动重抽，因此玩家拿到的牌一定存在满足本关条件的方案（见 [rules.md](../rules.md)）。
- 结构化条件只写本关特殊条件；三条永久通用规则由加载器自动叠加。
