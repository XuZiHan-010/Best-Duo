青色高亮 = 可放置区段
  • 1点击手牌中一张 → 该牌升起高亮，时钟盘上所有可放区段变青色
  • 2再点击目标区段 → 发送 card:place，牌进入 pending 态灰显，等服务端确认
  • 3点其他空白处或按 Esc → 取消选中，不发送
优点

缺点

  • 1鼠标按住手牌不松 → 牌跟随鼠标移动，区段出现落点高亮
  • 2拖到目标区段上方松开 → 发送 card:place
  • 3拖到时钟盘外松开 → 取消，牌回到手牌
优点
操作直觉感强
一步完成放置
缺点
手机拖拽体验差
倒计时紧张时更易误放
实现复杂度更高
推荐方案：A 为主，B 为桌面增强。
点选交互在移动端、键盘、低时延网络下都稳定；5 秒倒计时压力下「选牌 → 亮区段 → 点区段」的两步确认比拖拽更不容易出错。桌面端可以额外支持拖拽，两者发送的都是同一个 card:place 事件，后端无感知区别。
